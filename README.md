# inkscape-svg-asset-auditor

An Inkscape extension that audits SVG assets for missing IDs, duplicate IDs, and oversized files.

## Stack

Primary language: **Python**

## Project structure

- `inkscape_svg_asset_auditor.py` — Validate SVG structure and report asset quality issues within Inkscape.
- `requirements.txt` — dependencies
- `tests/test_main.py` — basic tests

## Usage

Review the source files and install any dependencies referenced by the project before running it.
